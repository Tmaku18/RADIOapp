# Firebase Quick Start Guide

## What You Need to Set Up Firebase

### For Mobile App (Flutter)

1. **Firebase Project** ✅ (`radioapp-4c14a`)
2. **google-services.json** for Android (app `com.tmaktechnologies.networxradio`)
3. **GoogleService-Info.plist** for iOS (bundle `com.tmaktechnologies.networxradio`)
4. **firebase_options.dart** (generated by `flutterfire configure`)
5. **Enable Authentication** in Firebase Console

### For Backend (NestJS)

1. **Service Account Key** (JSON, kept out of git)
2. **Environment variables** in `backend/.env`

### For Web (Next.js)

1. `NEXT_PUBLIC_FIREBASE_*` web config in `web/.env.local`
2. `FIREBASE_SERVICE_ACCOUNT_KEY` (service account JSON) for session cookies

## Step-by-Step Setup

### Step 1: Get Configuration Files from Firebase Console

1. Go to [Firebase Console](https://console.firebase.google.com/)
2. Select your project: **radioapp-4c14a**

#### For Android:
1. Click **⚙️ Project Settings** (gear icon)
2. Scroll to **"Your apps"** section
3. Find the **Android app** `com.tmaktechnologies.networxradio`
4. Download **google-services.json**
5. Place it in: `mobile/android/app/google-services.json` (replace existing)

#### For iOS:
1. Same Project Settings page
2. Find the **iOS app** `com.tmaktechnologies.networxradio`
3. Download **GoogleService-Info.plist**
4. Place it in: `mobile/ios/Runner/GoogleService-Info.plist` (replace existing)

### Step 2: Configure Flutter App (Easiest Method)

```bash
# Install FlutterFire CLI
dart pub global activate flutterfire_cli

# Navigate to mobile directory
cd mobile

# Run configuration (will ask you to select your Firebase project)
flutterfire configure
```

This automatically:
- Generates `lib/firebase_options.dart`
- Configures both Android and iOS
- Sets up everything you need

### Step 3: Enable Authentication

1. In Firebase Console, go to **Authentication** → **Sign-in method**
2. Enable:
   - ✅ **Email/Password** (toggle on, save)
   - ✅ **Google** (toggle on, enter support email, save)
   - ✅ **Apple** (used on iOS and the web)
3. Under **Authentication → Settings → Authorized domains**, include `networxradio.com`, `www.networxradio.com`, `pro-networx.com`, and `www.pro-networx.com` (see `docs/firebase-authorized-domains.md`)

Phone verification at sign-in is handled by the backend (Twilio), not Firebase phone auth.

### Step 4: Configure Backend

Easiest: point the backend at the downloaded JSON.

```env
FIREBASE_SERVICE_ACCOUNT_PATH=/absolute/path/to/service-account.json
```

Or copy the three fields from the JSON into `backend/.env`:

```env
FIREBASE_PROJECT_ID=radioapp-4c14a
FIREBASE_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\n<key body>\n-----END PRIVATE KEY-----\n"
FIREBASE_CLIENT_EMAIL=firebase-adminsdk-xxxxx@radioapp-4c14a.iam.gserviceaccount.com
```

**Important:** The private key must be on ONE line with `\n` characters, wrapped in double quotes. See `backend/FIREBASE_KEY_FORMAT.md`. Never paste a real key into docs or commits.

### Step 5: Verify Setup

#### Test Mobile App:
```bash
cd mobile
flutter clean
flutter pub get
flutter run
```

**Look for in console:**
- ✅ "Firebase initialized successfully"
- ✅ Welcome screen appears
- ❌ No "No Firebase App" errors

#### Test Backend:
```bash
cd backend
npm run start:dev
```

**Look for in console:**
- ✅ "Application is running on: http://localhost:3000"
- ❌ No "Firebase configuration missing" or "FIREBASE_PRIVATE_KEY appears to be invalid" errors

### Step 6: Test Authentication

1. Run the mobile app
2. Try to sign up with email/password
3. Check Firebase Console → Authentication → Users
4. You should see the new user created

## If You Get Stuck

### "No Firebase App '[DEFAULT]' has been created"
→ Make sure `google-services.json` is in the right place and not empty

### "Firebase is not initialized"
→ Run `flutterfire configure` or check `firebase_options.dart`

### Backend can't verify tokens
→ Use `FIREBASE_SERVICE_ACCOUNT_PATH`, or check `FIREBASE_PRIVATE_KEY` format in `.env` (must have `\n` characters)

### Google Sign-In not working
→ Add SHA-1 fingerprints (debug, upload, and Play App Signing) to Firebase Console (see `mobile/TROUBLESHOOTING.md`)
